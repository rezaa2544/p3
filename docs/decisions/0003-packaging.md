# ADR 0003 — بسته‌بندی نسخه‌ی ویندوزی با Node SEA

- **وضعیت**: پذیرفته‌شده
- **تاریخ**: ۲۰۲۶-۱۰-۲۳

## زمینه

مدرسه به نسخه‌ی ویندوزی «بدون نصب» نیاز دارد. گزینه‌های رایج:

| گزینه | مشکل در این محیط |
|---|---|
| Electron + electron-builder | دانلود پیش‌سازها/آیکون/امضا از GitHub Releases مسدود است |
| Node + `pkg` (منسوخ) | وابستگی به باینری‌های قدیمی Node 18 و رفتار ناسازگار با ESM/PGlite |
| نصب Node روی رایانه‌ی مدرسه | نیاز به دانش فنی و به‌روزرسانی دستی |

## تصمیم

- ساخت باندل واحد (esbuild، فرمت CJS) از `apps/api/dist/server.js` + جاسازی رابط کاربری،
  مهاجرت‌ها، `pglite.wasm` و `pglite.data` به‌عنوان دارایی‌های SEA.
- تزریق blob در باینری رسمی Node 26.12.1 (بسته‌های npm `node-win-x64` / `node-linux-x64`).
- بوت‌استرپ در نخستین اجرا دارایی‌ها را در `PAYESH2_HOME` استخراج و سرور را در همان
  فرایند بالا می‌آورد (بدون npm، بدون سرور جانبی).
- `import.meta.url` در خروجی CJS به آدرس واقعی فایل باندل وصله می‌شود تا PGlite بتواند
  مسیر wasm/data را حل کند (مسیرها با `PGLITE_WASM`/`PGLITE_DATA` هم صریح داده می‌شوند).

## پیامدها

- **مثبت**: یک فایل اجرایی ~۱۲۰ مگابایتی ویندوزی، بدون وابستگی خارجی؛ مسیر بوت/ورود همان
  کد تست‌شده در لینوکس است (باینری لینوکسی ساخته و اجرا شد).
- **منفی**: باینری امضای تجاری ندارد (هشدار SmartScreen)، هر ارتقا = دانلود مجدد ~۱۲۰MB،
  و **اجرای آن روی ویندوز واقعی آزموده نشده (NOT RUN)**.
- PGlite برای یک مدرسه/یک رایانه مناسب است؛ برای چند مدرسه باید PostgreSQL مدیریت‌شده
  استفاده شود.
