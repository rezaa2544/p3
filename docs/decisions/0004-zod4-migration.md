# ۰۰۰۴ — مهاجرت به zod 4 به‌دلیل CVE-2023-54404 و پیام‌های اعتبارسنجی فارسی

- تاریخ: ۲۰۲۶-۱۰-۲۳
- وضعیت: پذیرفته و اجرا شد

## زمینه

CI در کار «بررسی امنیت وابستگی‌ها» شکست خورد:

```text
zod  <4.6.6
Severity: high
Zod can exhaust memory while validating oversized constrained collections
https://github.com/advisories/GHSA-mrhx-c7xc-m3w5   (CVE-2023-54404, CVSS 8.2)
1 high severity vulnerability
```

پروژه روی `zod@^3.25.76` بود و `npm audit --omit=dev --audit-level=high` (معیارِ خودِ
workflow در `ci.yml`) کد خروج ۲ می‌داد.

## ارزیابی ریسک واقعی برای این محصول (پیش از تصمیم)

| پرسش | پاسخ با شاهد |
|---|---|
| آیا از الگوی آسیب‌پذیر (`z.array` بدون سقف) استفاده می‌شود؟ | فقط یک مورد: `apps/api/src/routes/attendance.ts` → `z.array(recordSchema).min(1).max(200)` — **سقف دارد** |
| آیا حجم بدنه محدود است؟ | بله، `bodyLimit: 2 * 1024 * 1024` در `apps/api/src/app.ts` |
| نتیجه | بهره‌برداری عملی بسته بود، اما معیار CI («صفر آسیب‌پذیری high») نباید شل شود |

## تصمیم

1. ارتقا به `zod@^4.6.7` (نسخهٔ وصله‌شده) در `apps/api/package.json`.
2. تنها تغییر لازم در کد: `z.record(z.unknown())` → `z.record(z.string(), z.unknown())`
   در `apps/api/src/routes/school.ts` (در zod 4 آرگومان کلید اجباری است).
3. فعال‌سازی بستهٔ زبان فارسی zod به‌همراه ترجمهٔ نام نوع‌ها در
   `apps/api/src/lib/zod-fa.ts` — تا پیام‌های اعتبارسنجی که در رابط کاربری دیده می‌شوند
   فارسی باشند، نه انگلیسی.

## شواهد پس از تغییر

| بررسی | نتیجه |
|---|---|
| `npm audit --omit=dev --audit-level=high` | `found 0 vulnerabilities` (کد خروج ۰) |
| `npm run typecheck` | بدون خطا (هر دو بسته) |
| `npm run test:api` | **۱۰۲ تست در ۱۴ فایل**، همه سبز |
| `npm run test:web` | ۳۳ تست، همه سبز |
| E2E مرورگر واقعی روی PostgreSQL 16.2 | **۲۳/۲۳** و **۷/۷** PASS |
| نمونهٔ پیام واقعی API | `{"path":"username","message":"ورودی نامعتبر: می‌بایست متن می‌بود، عدد دریافت شد"}` |

تست اختصاصی `apps/api/test/validation-i18n.test.ts` (۶ تست) هم فارسی‌بودن پیام‌ها،
دست‌نخورده‌ماندن پیام‌های سفارشی و نسخهٔ zod را تثبیت می‌کند تا این خطا برنگردد.

## پیامدها

- **مثبت**: CI سبز، آسیب‌پذیری high رفع شد، پیام‌های خطای فرم‌ها برای کاربر فارسی‌زبان
  قابل‌فهم شد، و یک تست تثبیت‌کننده اضافه شد.
- **منفی**: `.uuid()` و `.email()` در zod 4 منسوخ (deprecated) هستند ولی همچنان کار می‌کنند؛
  در آینده باید به `z.uuid()` / `z.email()` منتقل شوند. این کار عمداً در این تغییر انجام نشد
  تا مهاجرت کوچک و قابل‌بازبینی بماند.
- نسخهٔ zod در `apps/api` است، پس باندل‌های EXE/HTML دوباره ساخته و هش‌ها به‌روز شد.
