## آنچه در این نسخه کار می‌کند

- ورود/خروج، نشست کوکی، CSRF، نقش‌ها و مرز مدرسه (RLS).
- حضور و غیاب گروهی + اصلاح با تاریخچه، گزارش روزانه/کلاسی.
- ارزیابی، ثبت نمره، تأیید، کارنامه‌ی چاپی با میانگین وزنی و تاریخ جلالی.
- تکالیف، اطلاعیه، اعلان درون‌سامانه‌ای، پیوست فایل با کنترل نوع/حجم.
- داشبورد مدیر، گزارش‌ها، حسابرسی، تنظیمات مدرسه، مدیریت کاربران و دانش‌آموزان.
- PWA با صف آفلاین و همگام‌سازی idempotent.
- پشتیبان/بازیابی با checksum؛ نسخه‌ی ویندوزی تک‌فایل؛ HTML تک‌فایل.

## محدودیت‌های این نسخه (بدون پرده‌پوشی)

1. **استقرار اینترنتی انجام نشده** — آدرس HTTPS عمومی وجود ندارد (BLOCKED).
2. **اجرای فایل ویندوزی روی ویندوز واقعی آزموده نشده** (NOT RUN).
3. **APK اندروید ساخته شد** (CI با Android SDK رسمی، امضای v2+v3، بازبینی ایستا ۱۹/۱۹)، اما
   **روی گوشی واقعی آزموده نشده** و کلید امضایش «پایلوت» است. نصب‌کننده‌ی
   جداگانه (NSIS/WiX) هم ساخته نشده، اما **نیازی نیست**: همان `Payesh2.exe` خودش را per-user
   نصب می‌کند (میان‌بر منوی شروع/دسکتاپ، ثبت در «افزودن یا حذف برنامه‌ها»، حذف با `--uninstall`).
4. **آزمون E2E مرورگری انجام شده است** (HTML تک‌فایل ۷/۷ و جریان‌های محصول ۲۳/۲۳، شامل
   قطع واقعی شبکه)؛ آنچه هنوز آزموده نشده: اجرای ویندوزی روی ویندوز واقعی (مورد ۲)، آزمون
   بار روی PostgreSQL مدیریت‌شده (مورد ۷) و بازیابی از پشتیبان روی سرور جداگانه.
5. MFA فقط از مسیر API قابل فعال‌سازی است.
6. پیامک/ایمیل واقعی ندارد؛ اعلان‌ها درون‌سامانه‌ای‌اند.
7. آزمون بار روی **PostgreSQL 16.2 واقعی** انجام شد (۵ سناریو، ۰ خطا) و بازیابی از پشتیبان
   روی یک نمونه‌ی جداگانه PostgreSQL با شمارش یکسان و ورود موفق آزموده شد؛ اما روی سرویس
   مدیریت‌شده‌ی ابری/TLS انجام نشده است.
8. مدیریت «پایه‌ی تحصیلی» در رابط کاربری ۰.۱.۰ نیست (API آن موجود است)؛ می‌توان کلاس را
   بدون پایه ساخت یا پایه را از API افزود.

## نصب سریع

- **ویندوز**: روی `Payesh2.exe` دابل‌کلیک کنید؛ بدون پنجرهٔ کنسول نصب می‌شود و پنجرهٔ
  برنامه باز می‌شود. ورود نخستین: نام کاربری `123456` و رمز `123456` — سامانه تغییر رمز را
  اجباری می‌کند. راهنمای کامل: `docs/deployment/windows-desktop-howto.txt`.
- **از مخزن**: `npm ci && npm run build && npm run db:migrate && npm start`
  (برای داده‌ی نمونه‌ی توسعه: `SEED_DEMO=1 npm run db:seed`).

## نسخهٔ میزکار (۲۰۲۶-۱۰-۲۴)

- فایل اجرایی ویندوز دیگر کنسولی نیست: زیرسیستم PE به **GUI** تغییر کرد و آیکون/نسخه در
  منابع فایل جاسازی شد (`scripts/lib/pe.mjs`، بازبینی `npm run verify:win` → ۱۳/۱۳ PASS).
- همان فایل، نصب‌کننده هم است: نصب per-user در `%LOCALAPPDATA%\Programs\Payesh2`، میان‌بر
  منوی شروع/دسکتاپ/«حذف»، ثبت در رجیستری، بدون UAC.
- پنجرهٔ برنامه: سرور محلی روی `127.0.0.1:3210` + Edge در حالت `--app` (بدون نوار آدرس).
- اعتبارنامهٔ نخستین ورود `123456`/`123456` با پرچم صریح و تغییر رمز اجباری — ADR 0005.
- آزمون‌های جدید: `install-plan.test.ts`، `desktop-installer.test.ts`،
  `desktop-bootstrap.test.ts` (در مجموع API: ۱۷ فایل / ۱۳۰ تست) و کار CI «نسخه میزکار».
- آزمون مرورگری خودِ فایل اجرایی در CI: **۱۲/۱۲ PASS** (ورود با `123456`، کوکی httpOnly/Secure
  روی `127.0.0.1`، بنر تغییر رمز، سرویس‌ورکر PWA، رد رمز کوتاه، تغییر رمز و از کار افتادن رمز
  قدیمی) — `docs/testing/desktop-e2e.json`.

## نسخهٔ اندروید (۲۰۲۶-۱۰-۲۴)

- اپلیکیشن `apps/android/` (یک اکتیویتی WebView، بدون وابستگی خارجی) و APK امضاشده در
  `artifacts/payesh2-android.apk` (۱۴۴٬۶۸۶ بایت، sha256 در `artifacts/BUILD.md`).
- ساخت و امضا در کار CI «ساخت APK اندروید»: JDK 17 + SDK 34 + Gradle 8.9 → `assembleRelease`
  → `zipalign` → `apksigner` → `aapt2 dump badging` → `scripts/verify-apk.mjs` (۱۹/۱۹ PASS).
- نشانی سرور در نخستین اجرا پرسیده می‌شود (هیچ نشانی‌ای هارد‌کد نیست) — ADR 0006.
- اجرا روی دستگاه/شبیه‌ساز: **NOT RUN** (`docs/testing/07-android.md`).

## به‌روزرسانی امنیتی

`zod` به **۴.۶.۷** ارتقا یافت تا CVE-2023-54404 (GHSA-mrhx-c7xc-m3w5، شدت High) رفع شود؛
`npm audit --omit=dev --audit-level=high` اکنون **۰ آسیب‌پذیری** می‌دهد. همزمان بستهٔ زبان
فارسی zod فعال شد و پیام‌های اعتبارسنجی API فارسی شدند
(مثال: `ورودی نامعتبر: می‌بایست متن می‌بود، عدد دریافت شد`). توضیح کامل و شواهد:
`docs/decisions/0004-zod4-migration.md`.

## تغییرات مهم نسبت به پیش‌نویس‌های میانی

- رفع باگ واقعی: ایندکس یکتای `attendance_records.client_op_id` باعث شکست ۱۰۰٪ ثبت گروهی
  می‌شد؛ به `(client_op_id, student_id)` تغییر کرد.
- کوکی نشست به `payesh2_sid` تغییر نام داد (استقلال کامل از سامانه‌ی قبلی).
- افزودن `scripts/build-exe.mjs`، `scripts/build-standalone-html.mjs` و
  `scripts/build-release-zips.mjs` (بازتولیدپذیر).
- **رفع باگ نسخه‌ی HTML تک‌فایل**: باندل به‌صورت `<script type="module">` در `<head>` جاسازی
  می‌شد و پیش از ساخت `#root` اجرا می‌شد → خطای «ریشه برنامه یافت نشد» و صفحه‌ی خالی.
  اکنون باندل IIFE (سازگار با مرورگرهای قدیمی‌تر) در انتهای `<body>` درج می‌شود.
- افزودن «نگهبان بوت» (۶ ثانیه) و صفحه‌ی راهنمای فارسی برای حالت `file://` (به‌جای فرم ورودِ
  بی‌اثر)، و مسیر `GET /standalone.html` در API تا فایل از مبدأ درست سرو شود.
- آزمون مرورگر واقعی با Chromium: `npm run test:e2e:standalone` → ۷/۷ PASS و
  `npm run test:e2e:product` → ۲۳/۲۳ PASS.
- **رفع سه باگ واقعی که آزمون مرورگری پیدا کرد**: مسیر وابسته به `cwd` برای `web/dist`
  (همه‌ی مسیرها ۴۰۴ می‌دادند و رفرش صفحه کار نمی‌کرد)، پاسخ `index.html` برای فایل‌های
  ناموجود (`/assets/*.js` → خطای MIME و صفحه‌ی سفید)، و پریدن فوکوس مودال روی دکمه‌ی ✕
  (تایپ فارسیِ دارای فاصله مودال را می‌بست).
- **تکمیل قابلیت ناقص**: «اصلاح حضور با دلیل و تاریخچه» فقط در API بود و رابط کاربری نداشت؛
  اکنون دکمه‌ی «اصلاح» با دلیل الزامی و نمایش تاریخچه در صفحه‌ی حضور وجود دارد
  (`GET /attendance/:id/revisions`).
- افزودن `scripts/e2e-product.mjs`، `scripts/verify-win-artifact.mjs` (بازبینی ایستای PE) و
  تست‌های `test/web-static.test.ts`.
- اجرای کامل روی **PostgreSQL 16.2** (مهاجرت، بذر، E2E ۲۳/۲۳)، آزمون بار ۵ سناریویی با
  ۰ خطا و بازیابی پشتیبان ۳۲ جدول/۱۱۸٬۲۱۱ ردیف روی نمونه‌ی دوم — `docs/testing/04-real-postgres-restore.md`.
