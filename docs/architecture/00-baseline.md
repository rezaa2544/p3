### پیامدهای مستقیم برای خروجی‌ها

- **پایگاه داده:** PostgreSQL واقعی از طریق `@electric-sql/pglite` (PostgreSQL 18.6 روی WASM، با
  پروتکل wire واقعی) برای توسعه، CI و تست استفاده می‌شود. کد برنامه تنها با درایور `pg` صحبت می‌کند،
  بنابراین در تولید بدون تغییر به PostgreSQL مدیریت‌شده وصل می‌شود.
- **نسخه وب:** استقرار ابری نیازمند حساب/توکن میزبان است که در اختیار نیست → `BLOCKED`.
  سرویس به‌صورت زنده در سندباکس اجرا و از طریق URL پیش‌نمایش HTTPS قابل دسترسی است (موقت، نه تولید).
- **EXE:** ساخت بسته Electron برای `win32-x64` بدون Wine امکان‌پذیر است؛ ساخت **installer** (NSIS) نیاز به
  Wine دارد → در صورت عدم موفقیت `BLOCKED`.
- **APK:** بدون JDK و Android SDK و بدون دسترسی به مخزن بسته‌های آن‌ها → `BLOCKED`.
- **E2E مرورگر واقعی:** دانلود باینری Playwright از دامنه‌های مجاز ممکن نیست → `NOT RUN`.
  به‌جای آن تست‌های API سرتاسری واقعی (Fastify inject + HTTP زنده) و تست کامپوننت DOM اجرا می‌شود.
