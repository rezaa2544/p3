# بازبینی دسترس‌پذیری (WCAG 2.1 A/AA) با axe-core

تاریخ: ۲۰۲۶-۱۰-۲۳ · ابزار: **axe-core 4.14** تزریق‌شده در Chromium ۱۳۱ (مرورگر واقعی)
گزارش ماشین‌خوان: `docs/testing/a11y-report.json` · تصاویر: `docs/testing/evidence/a11y-*.png`
اجرا: `E2E_BASE=http://127.0.0.1:3400 npm run audit:a11y`

## دامنه

۱۲ صفحه، هر دو حالتِ بدون نشست و با نشست مدیر:
ورود · داشبورد · حضور و غیاب · گزارش حضور · ارزیابی و نمرات · کارنامه · تکالیف ·
اطلاعیه‌ها · دانش‌آموزان · کاربران و نقش‌ها · گزارش‌های مدیریتی · پیمایش با صفحه‌کلید.

قواعد: `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa` (تضاد رنگ، برچسب فرم، نام قابل‌دسترس،
ساختار عنوان، نقش‌های ARIA، landmarkها).


## ایراد واقعی که پیدا شد و رفع شد

| مورد | جزئیات |
|---|---|
| نشانه | ۱۱ صفحه، ۱ ایراد `serious` از نوع `color-contrast` |
| ریشه | متغیر رنگ `--c-muted: #7b8f93` برای متن‌های کم‌رنگ (عنوان گروه‌های منو، زیرنویس برند در صفحه‌ی ورود) → نسبت تضاد **۳.۳۹:۱** روی سفید؛ حد WCAG AA برای متن معمولی **۴.۵:۱** |
| رفع | `--c-muted: #5a6d71` → **۵.۴۴:۱** روی سفید، ۵.۱۱:۱ روی پس‌زمینه و ۴.۹۶:۱ روی سطح دوم |
| شاهد | `apps/web/src/styles/app.css` + گزارش بازاجراشده با ۰ ایراد در همه‌ی صفحه‌ها |

پیش از رفع، این ایراد در ۱۱ صفحه گزارش شد؛ پس از تغییر یک متغیر رنگ، اجرای دوباره **۰**
ایراد داد — یعنی آزمون واقعاً حساس است، نه تشریفاتی.

## آنچه این سند ادعا **نمی‌کند**

- آزمون با صفحه‌خوان واقعی (NVDA/JAWS/VoiceOver) — **NOT RUN**؛ axe فقط بخشی از مسائل را
  می‌بیند (تجربه‌ی شنیداری، ترتیب خواندن منطقی و کیفیت متن جایگزین را نمی‌سنجد).
- آزمون با کاربران کم‌بینا/ناشنوا و بزرگ‌نمایی ۴۰۰٪ — **NOT RUN**.
- بررسی جداگانه‌ی حالت چاپ از نظر دسترس‌پذیری — **NOT RUN** (چیدمان چاپ در
  `03-product-e2e.md` بررسی شده است).
