# آزمون نسخهٔ میزکار ویندوز

هدف: اثبات چیزهایی که می‌توان دربارهٔ «برنامهٔ دسکتاپ» ثابت کرد — و صریح گفتن چیزهایی که
در این محیط اثبات‌شدنی نیستند.

## لایهٔ ۱ — منطق خالص (هر سیستم‌عاملی)

| آزمون | فایل | چه چیزی را ثابت می‌کند |
|---|---|---|
| نقشهٔ نصب | `apps/api/test/install-plan.test.ts` | مسیرهای per-user مستقل از نام کاربری (فارسی/فاصله)، نقل‌قول ایمن PowerShell، ترتیب گام‌ها، رجیستری کامل (DisplayName/UninstallString/EstimatedSize)، اسکریپت حذف که داده را نگه می‌دارد، خنثی‌سازی تزریق در متن پیام |
| اجراکنندهٔ نصب/حذف | `apps/api/test/desktop-installer.test.ts` | کپی فایل، ساخت سه میان‌بر در یک اسکریپت، فقط `reg.exe` (بدون `cmd.exe`)، پاک‌سازی نصب نیمه‌کاره در شکست کپی، حذف بدون دست‌زدن به داده، رد درخواست نصب روی سیستم غیرویندوزی |
| حالت‌های اجرا | همان فایل | `--install`/`--uninstall`/`--server`/`--plan`/`--silent`/`--reinstall`، انتخاب مرورگر میزبان، آرگومان‌های `--app=`، `HOST=127.0.0.1`، کوکی Secure، اعتبارنامهٔ نخستین ورود |
| نخستین ورود | `apps/api/test/desktop-bootstrap.test.ts` | بدون پرچم صریح رمز کوتاه رد می‌شود؛ با پرچم حساب ساخته می‌شود؛ `must_change_password` همیشه true؛ تغییر رمز به رمز کوتاه با پیام فارسی رد می‌شود؛ رمز قوی پذیرفته می‌شود و رمز قدیمی از کار می‌افتد |

اجرا: `npm run test:api` (بخشی از CI).

## لایهٔ ۲ — بازبینی ایستای فایل اجرایی ویندوز

`npm run verify:win` → `artifacts/payesh2-win-static.json`

| بررسی | نتیجهٔ فعلی |
|---|---|
| امضای MZ + PE\0\0 | PASS |
| معماری x86-64 و PE32+ | PASS |
| **زیرسیستم GUI** (بدون پنجرهٔ کنسول) | PASS (`subsystem=2`) |
| آیکون در منابع PE | PASS |
| اطلاعات نسخه/محصول | PASS («پایش ۲ — Payesh 2» v0.1) |
| دارایی‌های `desktop.cjs`/`server.cjs`/`migrations`/`pglite.wasm`/HTML تک‌فایل | PASS |

این آزمون اجرا روی ویندوز را **اثبات نمی‌کند** و چنین ادعایی هم ندارد.

## لایهٔ ۳ — اجرای واقعی همان کد (لینوکس) + آزمون مرورگری

همان `cli.ts` و همان باندل سرور با باینری لینوکسی ساخته می‌شود
(`npm run artifact:exe:linux`) و روی خودِ فایل اجرایی آزموده می‌شود:

```bash
PAYESH2_HOME=$(mktemp -d) ./artifacts/payesh2 --plan      # نقشهٔ کامل نصب، بدون تغییر سیستم
PAYESH2_HOME=$(mktemp -d) PORT=3311 ./artifacts/payesh2 --server &
node scripts/e2e-desktop.mjs                               # Chromium واقعی
```

`scripts/e2e-desktop.mjs` این موارد را می‌سنجد: بازشدن صفحهٔ ورود فارسی/RTL، ورود با
`123456`/`123456`، بنر اجباری تغییر رمز، `httpOnly`/`Secure` بودن کوکی نشست روی
`http://127.0.0.1`، پایداری نشست پس از بارگذاری دوباره، فعال‌بودن سرویس‌ورکر PWA، رد شدن رمز
کوتاه در رابط کاربری، پذیرش رمز قوی و از کار افتادن رمز قدیمی. گزارش:
`docs/testing/desktop-e2e.json`.

> وضعیت این لایه: در CI (کار «نسخه میزکار») با نصب کتابخانه‌های سیستمی مرورگر اجرا می‌شود.
> در محیط توسعهٔ فعلی کتابخانه‌های Chromium (`libnss3` و….) نصب نیستند و دانلودشان از این
> محیط ممکن نشد؛ بنابراین آخرین اجرای محلی «NOT RUN» ثبت شده است (نه PASS). این تفاوت
> عمدی است: آزمون اجرانشده هرگز PASS گزارش نمی‌شود.

## چیزهایی که همچنان اثبات‌نشده‌اند

| مورد | وضعیت | چرا |
|---|---|---|
| اجرای `Payesh2.exe` روی ویندوز واقعی (نصب، میان‌بر، پنجرهٔ Edge، حذف) | **NOT RUN** | محیط ساخت لینوکسی است و ویندوز/ماشین مجازی در دسترس نیست |
| رفتار SmartScreen / امضای دیجیتال | **NOT RUN** | گواهی کد امضا (Code Signing) در دسترس نیست |
| بازکردن پنجره با Edge روی ویندوز | **NOT RUN** | انتخاب مسیر Edge و آرگومان‌ها آزمون واحد دارد، ولی اجرای واقعی ویندوزی نه |
